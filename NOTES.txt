RELEASE INSTRUCTIONS

  1. `git status` # Make sure all changes are commited!
  2. `make clean`; `make -j4 all combined`
  3. Use arbiter.py to run a competition with the new and previous players
  4. Check player logs for unexpected warnings/errors.
  5. Submit to CodeCup.
  6. `git tag submission-#-id-#`
  7. Make a backup: `cp -r output/ backups/$(git rev-parse --short HEAD)`

AFTER THE COMPETITION

  1. Download competition.csv and place in competition-results/
  2. Optional, if you get SSL errors due toe missing intermediate certificates
     export SSL_CERT_FILE=tools/codecup.pem (This may not be necessary anymore.)
  3. tools/fetch-competition-playerlogs.sh competition-XXX 'Maks Verver'
     (This will ask for the value of the codecupid cookie, which you can get by
     logging in at https://www.codecup.nl/ and then finding it in the Developer
     Tools under Application > Storage > Cookies.)
  4. tools/fetch-competition-transcripts.py tmp/cache/ \
      competition-results/competition-XXX.csv \
      competition-results/competition-XXX-transcripts.csv
  5. Symlink files:
     ln -s competition-XXX.csv competition-results/test-N-competition.csv
     ln -s competition-XXX-transcripts.csv competition-results/test-N-competition-transcripts.csv
     ln -s competition-XXX playerlogs/test-N
